# پورتفولیوی شخصی ابوالفضل – Frontend + Backend (Python)

این مخزن شامل کدهای یک وب‌سایت پورتفولیوی شخصی است که برای معرفی مهارت‌ها، پروژه‌ها و اطلاعات تماس یک **کارآموز بک‌اند با پایتون** طراحی شده است. رابط کاربری کاملاً فارسی و راست‌به‌چپ است و روی موبایل، تبلت و دسکتاپ به‌صورت ریسپانسیو نمایش داده می‌شود.

---

## ویژگی‌ها

- **طراحی مدرن تیره (Dark Theme)** هماهنگ با رنگ نارنجی برند (`#FF6A3D`).
- **پشتیبانی کامل از زبان فارسی و راست‌چین (RTL)** با فونت فارسی «Vazirmatn».
- **هدِر ثابت با منوی ناوبری** شامل لینک‌های:
  - خانه
  - درباره من
  - پروژه‌ها
  - تماس با من
- **افکت تایپ پویا در هدر** برای نمایش چند جمله معرفی:
  - من ابوالفضل هستم
  - کارآموز بک‌اند با پایتون
  - علاقه‌مند به جنگو و FastAPI
  - در مسیر یادگیری دیتابیس و تست‌نویسی
- **نمایش مهارت‌ها با نوار پیشرفت (Progress Bar)** برای:
  - HTML – ‎70%
  - CSS – ‎60%
  - Python – ‎40%
  - SQL – ‎50%
  - Git – ‎40%
  - GitHub – ‎70%
- **بخش پروژه‌ها** با کارت‌های جذاب و آیکون‌های اختصاصی برای هر پروژه:
  - شبیه‌ساز سیستم مدیریت بانک (Python, SQL)
  - ساخت پسورد تصادفی و امن (Python, CLI / Script)
  - تایمر (Python, CLI / Script)
  - Encrypt / Decrypt (Python, CLI / Script)
  - رزومه شخصی (HTML, CSS, JavaScript)
- **بخش تماس با من** شامل:
  - ایمیل
  - شماره تماس
  - آدرس
- **فوتر با لینک شبکه‌های اجتماعی**:
  - اینستاگرام
  - تلگرام
  - لینکدین
  - گیت‌هاب
- **لینک دانلود رزومه (PDF)** از طریق دکمه «رزومه من».
- **اسکرول نرم (Smooth Scroll)** برای حرکت بین بخش‌ها.
- **اسکرول‌بار سفارشی** با رنگ‌های هماهنگ با تم سایت.

---

## تکنولوژی‌ها و ابزارها

- **HTML5** – ساختار اصلی صفحه
- **CSS3 + Tailwind CSS (از طریق CDN)** – استایل‌دهی سریع و مدرن
- **JavaScript Vanilla** – افکت تایپ و رفتارهای تعاملی
- **فونت فارسی Vazirmatn** – از Google Fonts
- **Git & GitHub** – کنترل نسخه و میزبانی کد

## ساختار پروژه

```text
.
├── index.html      # صفحه اصلی پورتفولیو
├── style.css       # استایل‌های سفارشی (فونت، RTL، اسکرول‌بار، هاور منو و ...)
├── script.js       # افکت تایپ و منطق جاوااسکریپت
├── resume.pdf      # (اختیاری) فایل رزومه برای دانلود
└── README.md       # همین فایل توضیحات پروژه
```

> نکته: اگر `resume.pdf` را در پوشه پروژه قرار دهید، دکمه «رزومه من» در هدر، رزومه را برای کاربر دانلود/باز می‌کند.

## نحوه اجرا (لوکال)

برای مشاهده پروژه روی سیستم خودتان:

1. این مخزن را کلون کنید یا به‌صورت ZIP دانلود کنید:

   ```bash
   git clone https://github.com/USERNAME/REPO-NAME.git
   cd REPO-NAME
   ```

2. فایل `index.html` را مستقیماً با مرورگر باز کنید:
   - روی `index.html` دابل‌کلیک کنید **یا**
   - در ترمینال بزنید:

     ```bash
     # روی ویندوز
     start index.html

     # روی مک‌اواس
     open index.html

     # روی لینوکس (بسته به توزیع)
     xdg-open index.html
     ```

هیچ نیاز به سرور بک‌اند یا نصب پکیج اضافی نیست؛ این پروژه یک **Single Page Application استاتیک** است.

## انتشار روی GitHub Pages

اگر می‌خواهید این پورتفولیو را به‌صورت آنلاین و رایگان روی GitHub Pages منتشر کنید:

1. کد را روی گیت‌هاب پوش کنید (اگر از قبل نکرده‌اید):

   ```bash
   git add .
   git commit -m "Initial portfolio commit"
   git push origin main
   ```

2. در صفحه ریپوی خود در GitHub وارد **Settings** شوید.
3. از منوی کناری به بخش **Pages** بروید.
4. در قسمت **Branch**، شاخه `main` و مسیر `/root` را انتخاب و ذخیره کنید.
5. چند لحظه صبر کنید؛ یک URL به شما داده می‌شود مثل:

   ```text
   https://USERNAME.github.io/REPO-NAME/
   ```

این آدرس، لینک آنلاین پورتفولیوی شماست و می‌توانید آن را برای کارفرماها و دوستان بفرستید.

## شخصی‌سازی پروژه

می‌توانید این پروژه را به‌راحتی برای خودتان شخصی‌سازی کنید:

### ۱. تغییر نام، عنوان و معرفی

در فایل `index.html`:

- نام و عنوان در هدر:
  - نام (مثلاً «حسن امگا») را با نام خودتان عوض کنید.
  - عنوان شغلی (مثلاً «برنامه نویس پایتون») را متناسب با خودتان تغییر دهید.
- متن «درباره من» را با توضیح واقعی مسیر و علاقه‌مندی‌های خودتان جایگزین کنید.

### ۲. تغییر متن افکت تایپ

در فایل `script.js`، آرایه `texts` را پیدا کنید و متن‌های دلخواه خودتان را بگذارید:

```js
const texts = [
  'من ابوالفضل هستم',
  'کارآموز بک‌اند با پایتون',
  'علاقه‌مند به جنگو و FastAPI',
  'در مسیر یادگیری دیتابیس و تست‌نویسی',
];
```

می‌توانید جمله‌ها را کم و زیاد کنید یا کاملاً تغییر دهید.

### ۳. ویرایش مهارت‌ها و درصدها

در بخش «درباره من» داخل `index.html`، هر مهارت یک نوار پیشرفت دارد. برای تغییر درصد:

- متن درصد را عوض کنید (مثلاً `70%`).
- مقدار `width` نوار داخلی را مطابق همان درصد تنظیم کنید (مثلاً `style="width: 70%;"`).

### ۴. تغییر پروژه‌ها

در بخش «پروژه‌ها» در `index.html`، هر کارت یک پروژه است. می‌توانید:

- عنوان پروژه، توضیح کوتاه و تکنولوژی‌ها را عوض کنید.
- آیکون SVG را اگر دوست داشتید با آیکون دیگری جایگزین کنید.

### ۵. تنظیم لینک شبکه‌های اجتماعی

در فوتر `index.html` لینک‌ها را با یوزرنیم واقعی خودتان جایگزین کنید:

- اینستاگرام: `https://instagram.com/USERNAME`
- تلگرام: `https://t.me/USERNAME`
- لینکدین: `https://www.linkedin.com/in/USERNAME`
- گیت‌هاب: `https://github.com/USERNAME`

کافی است `USERNAME` را با یوزرنیم واقعی خودتان عوض کنید.

### ۶. اضافه کردن رزومه PDF

- فایل رزومه‌ی خودتان را به نام `resume.pdf` در ریشه پروژه کنار `index.html` قرار دهید.
- دکمه «رزومه من» در هدر به‌صورت خودکار به این فایل لینک می‌دهد و کاربر با کلیک روی آن رزومه را دانلود/باز می‌کند.
